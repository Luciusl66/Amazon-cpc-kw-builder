# CPC 手动投放策略

计划表候选为 S/A 相关、非仅相似品且未被档案列为精准否词的关键词。一级词以 60% 核心竞品覆盖率为高覆盖门槛。核心竞品分母为档案中的种子及直接竞品总数。覆盖率未知的一级词进入观察活动。

| 级别 | 建议结构 | 匹配 | 备注 |
| --- | --- | --- | --- |
| 一级，覆盖率 ≥60% | 按关键词独立活动 | Exact | 新品控预算/观察 |
| 一级，覆盖率 <60% 或未知 | 共用观察活动，按词根分组 | Exact | 控预算/观察 |
| 二级 | 同词根分组，精准和词组活动分开 | Exact、Phrase | Phrase 挂前置否词 |
| 三级 | 按标准词根归组 | Exact | 新品期核心出单引擎 |
| 四级、S级 | 超长尾和高意图无核分别打包 | Exact | 低竞价捡漏 |
| 零级与其他相关性 | 总库中保留 |  |  |

同表按月搜索量从大到小呈现，≥10,000 为高，1,000 至 9,999 为中，低于 1,000 为低，缺失为未知。表内的「CPC 建议竞价」沿用市场报表，长尾低竞价为策略备注。

前置否词 A 区按冲突词根去重，按涉及关键词月搜索量合计排序；B 区收录品牌全词与档案指定的多义精准排除。对被档案列为精准排除的冲突词根，改用对应完整查询做 Negative Exact。投放前按活动业务范围核对否词适用性。

增量趋势比较两次可比周期的生效搜索量，同周期上升或下降至少 20% 标为 TREND_UP 或 TREND_DOWN。首次出现标为 NEW，其他聚合变化标为 EXISTING。原样重跑保留已有状态。
