# 语义分级与打标契约

| 级别 | 判定 |
| --- | --- |
| 0级-泛品类词 | 上位大类、泛品类或缺乏明确本品意图的无核词 |
| 1级-核心大词 | 核心品类，无实质限定 |
| 2级-核心属性词 | 核心品类加 1 个限定 |
| 3级-精准细分词 | 核心品类加 2 个限定 |
| 4级-超级长尾词 | 核心品类加 3 个或更多限定 |
| S级-高意图无核词 | 缺少核心词根，产品档案能支撑明确的本品转化场景 |

识别核心词根的单复数与同义表达。先匹配最长复合限定，再排除停用词，最后按独立语义限定计数。诸如 “925 sterling silver” 和 “gift for her” 各计一次。标准词根优先使用产品档案中的单数核心词根与规范属性，顺序为「属性 + 核心品类 + 人群/场景」。删除无语义作用的介词和冠词，保留固定搭配必要成分。同义表达共享标准词根，原关键词和市场搜索量各自保留。

相关性只取 `S-核心精准`、`A-高度相关`、`B-弱相关扩展`、`X-属性冲突`、`P-竞品品牌`、`待复核`。S 明确贴合产品，A 与本品强相关，B 为弱相关扩展，X 为互斥属性/规格或红线，P 为竞品品牌。不能从档案判断时标记待复核。本地规则额外使用 `X-无效词/ASIN`，规则排除词可以没有语义级别。

一个输出文件是 JSON 数组。同编号输入中的每个键必须且只能出现一次，沿用原字符串。以下为一项。

```json
{
  "normalized_keyword": "sterling silver rings for women",
  "zh_meaning": "女士纯银戒指",
  "level": "3级-精准细分词",
  "canonical_root": "sterling silver ring for women",
  "relevance": "S-核心精准",
  "conflict_terms": [],
  "reason": "核心品类 ring，加纯银材质和女士人群两个限定"
}
```

AI 对 X 类逐个抽取真实出现的单词或双词短语。例如 `14k gold ring` 的冲突词根可写 `["14k", "gold"]`。多词查询不能整句复制到冲突数组。其余相关性的冲突数组为 `[]`。多义排除词在产品档案 `exact_negatives` 指定，批次结构保持统一。校验器检查证据、成员和格式；语义结论由抽检确认。

人工改级或改相关性之后，在总库的 `Manual_Lock` 填 TRUE 或「是」再运行导入。冲突词可用顿号、逗号分隔，也接受 JSON 字符串数组。已入库锁定持续生效。
